# Game Dev Tool Radar — May 15 to June 15, 2026

**Audience:** solo Unity developer on Windows + RTX GPU.
**Scope:** tools released or significantly updated in the last 30 days.
**Rule:** anything announced before May 15, 2026 is excluded, even if it's
newly popular. Near-misses are listed at the bottom of each section so
they're not lost.

## Character / animation AI

### ComfyUI-MotionCapture (GVHMR wrapper) — repo updates **May 2026**
- **What:** extracts SMPL params + 3D skeletal motion from video inside
  ComfyUI; retarget to Mixamo/UE mannequin downstream.
- **Price:** Free / open-source.
- **Relevance for solo Unity dev:** **7/10** — cheap pipeline for
  enemy/NPC anims if you already run ComfyUI.
- **Windows + RTX:** yes; ~8-12 GB VRAM for GVHMR.
- **Link:** https://github.com/PozzettiAndrea/ComfyUI-MotionCapture
- **FLAG:** ComfyUI workflow upgrade — adds a motion-capture node graph.

### DEMoCap Tools v1.8.1 (Blender add-on) — **May 28, 2026**
- **What:** open-source mocap toolset; this release adds long-message
  support in DNP via DENetwork-1.2 (networking-only fix).
- **Price:** Free.
- **Relevance:** **4/10** — niche networking patch, not a feature jump.
- **Windows + RTX:** yes (CPU-bound).
- **Link:** https://extensions.blender.org/add-ons/democap-tools/

Near-misses excluded by date: **Cascadeur 2026.1** (Apr 9 — Filament
renderer, UE Live Link, AI Root Motion, quadruped AutoPosing — would be
a 9/10 if it were in window) and **Reallusion iClone Video Mocap**
(Apr 2). Both are worth installing now if you do anim work; they just
didn't land in this 30-day window.

Nothing else in window: no verified May 15-Jun 15 update for
Scenario.gg, Layer.ai, Leonardo, Midjourney, Ideogram, or Flux.

## Pipeline automation

### Unity DevOps — new pricing/packaging (active since **Mar 1, 2026**, promo period running through window)
- **What:** Unity scrapped per-seat cloud UVCS billing, 5×'d free
  storage to 25 GB, gave 100 GB free egress, increased free build
  concurrency, unified storage/egress meters across UVCS + Unity Build
  Automation. Egress was free March/April.
- **Price:** Free tier dramatically larger; overages metered in GB
  storage and GB egress.
- **Relevance:** **9/10** — the new free tier covers most solo projects
  entirely. Re-evaluate if you were on the old pricing.
- **Windows + RTX:** yes (client-side).
- **Link:** https://support.unity.com/hc/en-us/articles/34748492914964-Understanding-New-Unity-DevOps-charges-starting-from-Mar-1-2026

### GameCI unity-builder (GitHub Actions) — in-window commits
- **What:** OSS GitHub Actions for building Unity; recent commits added
  `buildProfile` parameter and bumped cache/core deps for
  `upload-artifact v4`.
- **Price:** Free (GitHub Actions minutes apply).
- **Relevance:** **8/10** — cheaper than Unity Build Automation for low-
  volume work; `buildProfile` matters if you use Unity 6's build profiles.
- **Windows + RTX:** yes (runners can be Windows).
- **Link:** https://github.com/game-ci/unity-builder/releases

## Methodology / caveats

- **Window:** strict May 15-Jun 15, 2026. Items dated outside, even by a
  day or two, are listed as near-misses rather than included.
- Web search surfaces a lot of evergreen "Best of 2026" listicles that
  inflate "new" claims without firm dates. Anything not pinned to a
  dated source was dropped.
- The 3D asset gen and procgen categories were genuinely quiet this
  window. Sloyd 2.0 (Apr 18), Cascadeur 2026.1 (Apr 9), Unity AI Open
  Beta (May 4), and Convai NPC AI Engine v4.2.0 (May 11) all just missed
  the window — all worth installing if you haven't yet, but they belong
  in the May radar.
- Highest-value follow-up if you want to tighten this: check GitHub
  release/commit history directly for `Tencent-Hunyuan/*`,
  `microsoft/TRELLIS`, `VAST-AI-Research/TripoSR`, and `Comfy-Org` orgs
  between the exact dates — public articles miss patch-level releases.
