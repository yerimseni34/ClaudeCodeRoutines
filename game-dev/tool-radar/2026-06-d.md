# Tool Radar — June 2026

Scope: tools released or significantly updated in the ~30 days leading up to 2026-06-29, aimed at a solo Unity developer on Windows + RTX. Relevance scores reflect the solo-Unity perspective, not absolute quality.

Legend for Windows/RTX column: **yes** = runs locally and benefits from the GPU; **cloud** = browser/SaaS, GPU not used; **unknown** = couldn't confirm.

## Top picks (read these first)

- **Cursor Composer 2.5** — Cursor's in-house agentic model is the most consequential coding-tool shift this month, especially in light of GitHub Copilot's June 1 switch to usage-based AI Credits, which broke many heavy users' budgets overnight.
- **Meshy 6** — improved quad topology + direct Unity export; the closest thing to a one-tab text → game-ready mesh pipeline a solo dev can use.
- **Utility Intelligence (ECS) v1.x (Apr 19 update)** — slightly outside the 30-day window but the only real new entrant in the enemy-AI space; a DOTS-native Utility AI framework that's a direct upgrade to hand-rolled behavior trees.
- **Super Duper Batch Exporter** and **Export Helper Pro** — both materially improve the Blender → Unity FBX round-trip.

## Direct-upgrade flags

### Direct upgrade to a ComfyUI workflow

For solo devs tired of CUDA/driver/Python hell, three credible cloud-canvas replacements landed/matured this window:

- **Martini** — node canvas across 50+ frontier image/video models, strongest for multi-modal. https://martini.art/
- **Wireflow** — same node paradigm, browser only, no GPU. https://www.wireflow.ai/
- **MoodNode** — browser canvas across ~50 models (Flux/Kling/Veo). https://moodnode.ai/
- **Layer Workflow Builder** — node-based pipeline editor across image/video/3D/audio on Layer infra. https://www.layer.ai/

If you want to *keep* your ComfyUI graphs as-is but run them on rented GPUs, the managed-ComfyUI route (Comfy Cloud, RunComfy, ComfyDeploy, RunningHub, Promptus) is the lift-and-shift answer.

### Direct upgrade to a Blender → Unity pipeline

- **Super Duper Batch Exporter** — collection-driven one-click batch FBX export with auto-LOD, free; replaces hand-tweaking the FBX exporter dialog every time.
- **Export Helper Pro (2026)** — paid sibling that adds a dedicated N-panel tab with Unity/Unreal presets.
- **EdyJ blender-to-unity-fbx-exporter** — still the canonical fix for Blender's broken axis/scale into Unity; free and now updated for Blender 4.x. https://github.com/EdyJ/blender-to-unity-fbx-exporter

### Direct upgrade to enemy AI systems

- **Utility Intelligence (ECS)** — Utility AI for Unity DOTS, updated April 2026. If you've ever written a tangled `if`-chain or a brittle behavior tree, this is the cleaner pattern, and it's the only one targeting ECS performance.
- **Unity Behavior Graph package** — first-party visual behavior trees, now mainstream in Unity 6 tutorials and worth re-evaluating if you bounced off it earlier in the year.
- **Fluid Behavior Tree (OSS)** — code-driven builder-pattern BT for projects that don't want a visual editor. https://github.com/ashblue/fluid-behavior-tree
