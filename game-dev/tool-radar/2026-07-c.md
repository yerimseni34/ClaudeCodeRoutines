# Tool Radar — 2026-07

Scan date: 2026-07-27. Window: releases and significant updates in the ~30 days prior (roughly 2026-06-27 to 2026-07-27). Scored for a **solo Unity developer on Windows + RTX**.

Scoring key: **Rel** = solo-Unity relevance (1–10). **RTX** = confirmed to run on a Windows RTX box (yes / no / unknown).

Only tools with a dated release or update that lands in-window are marked "In-window". A short "Adjacent" section covers late-Q2 items that are still fresh and worth knowing but sit just outside the 30-day fence.

---

## Flagged: direct upgrades to your active workflows

- **Blender → Unity pipeline** — **Unity CLI + Unity Pipeline** (announced at Unite Seoul, 2026-07-21). Free MCP server + CLI + public API mean asset-import, build, and analytics steps can run headlessly next to a Blender export step. The first credible "no-Editor-in-the-loop" pipeline story from Unity itself. See Unity 7 entry below.
- **Blender → Unity pipeline** — **Blender 5.2 LTS** (2026-07-14). Two-year LTS baseline for the Blender side of the pipeline; matters mostly because pinning the version stabilises FBX/glTF exports. Also new: XPBD hair/cloth via Geometry Nodes.
- **ComfyUI workflow** — nothing genuinely new **in-window**. The relevant upgrade is still Hunyuan 3D 3.0 in ComfyUI Partner Nodes (Feb 2026) plus the newer PreviewGaussianSplat / PreviewPointCloud nodes. If you don't have those wired up yet, that's the upgrade path this month.
- **Enemy AI systems** — **Behavior Tools For Unity** (2026-06-05, just outside the window). Sits on top of Unity's free Behavior Graph and ships 200 low-level actions + gizmos + A*/Feel/SensorToolkit2 integration. The strongest "buy vs. write" behavior-tree story for a solo dev right now.
