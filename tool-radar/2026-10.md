## Flagged direct upgrades

Three upgrade targets were called out explicitly. What the scan found:

### ComfyUI workflow upgrade
- **ComfyUI v0.39.0** — reported release 2026-10-05 by a German tutorial
  site; adds a DynamicGroup widget and updates to ElevenLabs, Save EXR, Save
  Video nodes. **Not confirmed on the official changelog**, which currently
  tops out at v0.26.2 (2026-06-25). Treat as plausible; verify at the
  Comfy-Org GitHub releases page before adopting.
- The confirmed June 2026 release (v0.26.2) added PreviewGaussianSplat and
  PreviewPointCloud nodes — a real upgrade for anyone generating 3D previews
  inside Comfy workflows.

### Blender-to-Unity pipeline upgrade
- **PROTO Game Asset Tools** (Blender Artists, 2026-09-05) — new addon
  "optimized for Unreal, Unity, and Godot". **[IN WINDOW]**
- **GameDev Batch Render & Export** (Blender Artists, 2026-09-03) — thumbnail
  and multi-engine export addon. **[IN WINDOW]**
- Both are strong candidates for replacing hand-rolled FBX export scripts.
  Verify Blender 4.5 compatibility on the Artists thread before committing.

### Enemy AI systems upgrade
- **Behavior Tools For Unity** — launched roughly 2026-06 (50%-off new-release
  discount ran to 2026-06-16); builds on Unity's free Behavior package with
  ~200 pre-built actions, 15 conditions, 9 gizmos. **[LATEST, PRE-WINDOW]**
- No stronger entrant surfaced inside the window. **Opsive Behavior Designer
  Pro** remains the DOTS-ready paid incumbent.

## AI-POWERED TOOLS

### 3D asset generation

**Rodin Gen-2.5** (Hyper3D / Deemos)
1. Hosted text/image-to-3D with watertight geometry and PBR textures.
2. Subscription tiers; pricing not published in results — check hyper3d.ai.
3. Relevance: **7/10** — fastest path from concept art to blockout.
4. Windows + RTX: yes (web app; no local GPU needed).
5. https://hyper3d.ai
6. **[LATEST, PRE-WINDOW]** — Gen-2.5 cited in July 2026 roundups.

**Tripo v3.1**
1. Hosted text/image-to-3D with low-poly export option for game-ready meshes.
2. Free tier + paid credits (exact pricing per vendor).
3. Relevance: **7/10** — low-poly mode is specifically useful for solo devs.
4. Windows + RTX: yes (web).
5. https://www.tripo3d.ai
6. **[LATEST, PRE-WINDOW]**

**Hunyuan3D 2.1 / 3.0** (Tencent)
1. Open-weight image-to-3D model with downloadable checkpoints.
2. Free (open source) + hosted tier.
3. Relevance: **6/10** — strong if you want it fully local on an RTX card.
4. Windows + RTX: yes (local inference; VRAM-hungry).
5. https://github.com/Tencent/Hunyuan3D
6. **[LATEST, PRE-WINDOW]**

**Meshy-6**
1. Text/image-to-3D with Low Poly Mode and sharper hard-surface edges.
2. Free tier; Pro at $20/month.
3. Relevance: **8/10** — explicitly game-ready output.
4. Windows + RTX: yes (web).
5. https://www.meshy.ai
6. **[LATEST, PRE-WINDOW]** — v6 shipped January 2026.

## Top recommendations for a solo Unity dev (Windows + RTX)

1. **Install Unity's Claude Code plugin** — free, in-window, direct upgrade
   to an existing AI coding setup. The clearest win of this radar.
2. **Try the Blender PROTO / Batch Export addons** on your next asset — both
   land in-window and target the Blender→Unity pipeline directly.
3. **If running local 3D gen on your RTX, upgrade to Hunyuan3D 2.1** — the
   current best open-weight image-to-3D for local inference.
4. **Verify ComfyUI v0.39.0** on the Comfy-Org GitHub before updating; the
   release date comes from a single secondary source.
5. **Hold** on paid playtesting tools until you have a vertical slice;
   nothing in-window changes that calculus.
