# Tool Radar — October 2026

Scope: tools released or significantly updated roughly in the last 30 days
(late Sept → late Oct 2026), filtered for a solo Unity dev on Windows with
an RTX GPU. Scores are a judgment call for that profile, not an absolute
ranking. Sources are mostly vendor pages and review blogs — dates and
feature claims are secondary unless noted.

Compiled: 2026-10-26 (automated run — "Tool Radar" routine).

---

## 🚩 Direct upgrades flagged

- **ComfyUI pipeline:** Ubisoft's open-sourced **CHORD** model + ComfyUI
  nodes for end-to-end PBR material generation is the biggest step up
  from a hand-rolled SDXL+ControlNet tileable-texture chain. Still the
  only first-party-studio release of its kind.
- **Blender → Unity pipeline:** **BlendUnity Ultimate Toolkit** (addon +
  Unity package pair) with FBX manifests, Principled-BSDF → Unity
  material translator, LOD chain, and humanoid retargeting is a cleaner
  replacement for the usual "export fbx + hand-fix materials" loop.
- **Enemy AI systems:** **Behavior Tools For Unity** sits on top of
  Unity's official `com.unity.behavior` (1.0.8) and adds ~200
  actions / 15 conditions. If you were building against raw behavior
  trees, this is the drop-in upgrade.

## AI — 3D asset generation

### Meshy 7.1 — ⭐ most relevant this month
- **What:** Browser-based text/image-to-3D with PBR, auto-rigging, Unity
  / Unreal / Blender export; v7.1 shipped Sept 10, 2026 with
  higher-res geometry, 8K base-color textures, and an "Ultra 4K" mode.
- **Price:** Free tier (preview-only); paid plans required to download
  v7 meshes (vendor-stated).
- **Relevance (solo Unity):** 9/10 — closest to a one-shot prop
  generator that lands game-ready assets.
- **Windows + RTX:** Yes (fully hosted; GPU not required).
- **Link:** <https://www.meshy.ai/>

### Tripo — Smart Mesh (P1.0)
- **What:** Text/image-to-3D with ~2s quad retopology for cleaner
  topology than default marching-cubes output.
- **Price:** Freemium (hosted credits).
- **Relevance:** 7/10 — complements Meshy; use when topology matters.
- **Windows + RTX:** Yes (hosted).
- **Link:** <https://www.tripo3d.ai/>

### 3D AI Studio (aggregator)
- **What:** Single UI that routes to Rodin, Tripo, Hunyuan3D, TRELLIS;
  useful when you don't want to pay four subscriptions.
- **Price:** Paid subscription (tiered).
- **Relevance:** 6/10 — convenience, not a new capability.
- **Windows + RTX:** Yes (hosted).
- **Link:** <https://www.3daistudio.com/>

### Context: open-weight state
- **TRELLIS.2** (MIT, 4B params, PBR) — last release Dec 2025.
- **Hunyuan3D 3.1** (hosted, Jan 2026); last open weights = 2.1 (Jun 2025).
- **Rodin Gen-2.5** (hosted only, May 2026).
No fresh October drops among these three — the live movement this
month is in hosted products (Meshy 7.1).

## ComfyUI — game-asset nodes

### Ubisoft CHORD (open-sourced) ⭐
- **What:** Open-weights model + ComfyUI nodes + example workflows
  for end-to-end PBR material generation (texture gen + image →
  material estimation). Direct upgrade to a hand-rolled SDXL +
  ControlNet tileable chain.
- **Price:** Free (OSS, weights released).
- **Relevance:** 9/10 — on an RTX card, this is where to spend time
  this month.
- **Windows + RTX:** Yes (requires local VRAM; sized for 24 GB cards).
- **Link:** <https://blog.comfy.org/p/ubisoft-open-sources-the-chord-model>

### comfyui-ai-gamedev (mattwilliamson)
- **What:** ComfyUI nodes bundling **Hunyuan3D 2.1** (image → textured
  GLB) + an Ollama prompt extender.
- **Price:** Free (OSS).
- **Relevance:** 8/10 — the most practical "local image → textured
  GLB" chain for Unity.
- **Windows + RTX:** Yes.
- **Link:** <https://github.com/mattwilliamson/comfyui-ai-gamedev>

### ComfyUI-GameAssetsMaker (quinteroac)
- **What:** Custom nodes for visual-novel sprite atlas gen and
  rig-building via controlnet_aux.
- **Price:** Free (OSS).
- **Relevance:** 6/10 — niche but useful if you're on a VN / 2D
  project.
- **Windows + RTX:** Yes.
- **Link:** <https://github.com/quinteroac/ComfyUI-GameAssetsMaker>

### Platform note — ComfyUI Nodes 2.0 (beta)
- Enables per-node version pinning (good for workflow stability) but
  Nodes 2.0 can break existing workflows (overlap, lost
  seed-randomize controls). Hold off upgrading on anything you've
  invested time in.

### Caveats

- Most dates and feature claims come from vendor pages or review
  blogs. Verify release dates and licensing on each vendor's own
  release notes before committing a project to a tool.
- Hosted AI tools can change pricing fast — treat the Price lines as
  "as of the research date," not quotes.
- Open-weight 3D models (CHORD, TRELLIS.2, Hunyuan3D 2.1) have
  non-trivial VRAM footprints; verify your RTX card has the memory
  before relying on local inference.
