# Tool Radar — 2026-10

Scope: tools released or significantly updated in the ~30 days before 2026-10-05, filtered for a solo Unity dev on Windows with an RTX GPU. Relevance is scored for that persona (1 = ignore, 10 = install today).

Legend: **UPGRADE PATH** flags items that are direct upgrades to one of the tracked workflows — ComfyUI, Blender→Unity pipeline, or enemy AI systems.

---

## AI-powered tools

### 3D asset generation

**Meshy 7.1 (Ultra 4K)** — Text/image → game-ready mesh with the new Ultra 4K geometry mode and a `geometry_resolution` parameter replacing `ultra_mode`.
- Price: free tier (200 credits/mo); Pro $20/mo, Max $60/mo. 4K costs +5 credits per generation.
- Relevance: 9
- Windows + RTX: yes (cloud-hosted; browser works anywhere)
- Link: https://docs.meshy.ai/en/api/changelog
- **UPGRADE PATH (ComfyUI)**: a Meshy node pack is already in community ComfyUI builds — Ultra 4K drops in without workflow changes and is a direct quality bump over the Trellis/HY3D local nodes you'd otherwise chain.

**Chaos Cosmos AI (beta)** — Single reference image → 3D asset inside the Chaos Cosmos library, backed by Tencent HY 3D and Microsoft Trellis.2.
- Price: free during beta (Cosmos library itself is free with any Chaos product; standalone Cosmos account is also free).
- Relevance: 6 (handy for prop blockouts; architectural lean)
- Windows + RTX: yes (cloud generation; local viewer runs fine on RTX)
- Link: https://www.cgchannel.com/2026/09/new-cg-software-you-may-have-missed-13-september-2026/

**Ludo.ai 3D Generator (Sep 2026 refresh)** — Text/image/model-conditioned 3D generation with Text-to-3D, Image-to-3D, and separate Texture Generation modes.
- Price: free tier; paid plans from $15/mo.
- Relevance: 6
- Windows + RTX: yes (cloud)
- Link: https://ludo.ai/features/3d-generator

### Character / animation AI

**V2Fun (2026 Unity + Unreal pipeline)** — Text/image → rigged character + motion with Unity and Unreal retargeting out of the box.
- Price: free tier; subscription from ~$19/mo.
- Relevance: 7
- Windows + RTX: yes (cloud)
- Link: https://v2fun.ai/blog/ai-animation-software-unity-unreal-2026

**Cascadeur (production-ready for indies in 2026)** — Physics-aware keyframe animation with AI auto-posing and AutoPhysics. Called out in 2026 round-ups as the most production-ready AI animation tool for indies.
- Price: Basic free (non-commercial, 120 fps cap, watermark-free); Pro $29.99/mo or $299/yr; Business $99/mo.
- Relevance: 9
- Windows + RTX: yes (native Windows build; GPU accelerates viewport)
- Link: https://cascadeur.com/

### Concept art / 2D assets

**PixelLab** — Pixel-art sprite generator with one-click 4- and 8-directional sprite rotations, animation frames, and tileable backgrounds.
- Price: free tier; Pro $10/mo, Studio $25/mo.
- Relevance: 8 (strongest option if you ship pixel art)
- Windows + RTX: yes (web + Aseprite plugin)
- Link: https://www.pixellab.ai/

**Scenario (style-locked asset packs)** — Train a model on your own art bible, then generate hundreds of consistent props/UI/backgrounds.
- Price: free trial; Creator $12/mo, Professional $45/mo, Team $110/mo.
- Relevance: 8 (highest when consistency across many assets matters)
- Windows + RTX: yes (cloud; also has a Unity plugin)
- Link: https://www.scenario.com/

**SpriteFlow** — Sprite-sheet and walk-cycle generator; ~3 min for an 8-frame walk cycle.
- Price: free tier (limited credits); paid from $9/mo.
- Relevance: 6
- Windows + RTX: yes (web)
- Link: https://spriteflow.io/

### AI-assisted coding (beyond Copilot)

**Google Antigravity 2.0 (May 2026, iterating since)** — Multi-agent IDE replacing Gemini CLI / Code Assist; dynamic subagents, scheduled background tasks, a Go-based `antigravity` CLI, and a public SDK, running on Gemini 3.5 Flash.
- Price: free tier; Pro $20/mo, Ultra $200/mo (bundled with Google AI Pro/Ultra).
- Relevance: 7 (worth a Unity-project trial; multi-agent fits asset+code tasks)
- Windows + RTX: yes
- Link: https://antigravity.google/

**AWS Kiro (global launch May 2026)** — Ground-up replacement for Amazon Q Developer; spec-driven agent IDE.
- Price: free tier (50 agent requests/mo); Pro $19/mo (225 requests), Pro+ $39/mo.
- Relevance: 5 (less Unity-aware than peers)
- Windows + RTX: yes
- Link: https://kiro.dev/

**OpenAI Codex macOS → Windows parity (90+ plugins, SSH devboxes)** — Agent-first command center with background computer use, memory, in-app browser, GitHub review comments, remote devboxes.
- Price: free tier; ChatGPT Plus $20/mo, Pro $200/mo, Business $25/user/mo.
- Relevance: 6
- Windows + RTX: yes (Windows app parity confirmed in 2026 rollouts)
- Link: https://openai.com/codex/

**Goose (Block, open-source)** — Local-first agentic framework; writes/executes code, debugs, interacts with the file system; model-agnostic.
- Price: free (OSS; you pay the model API separately).
- Relevance: 6 (great for scripting Unity asset pipelines locally)
- Windows + RTX: yes (local; can run against local Ollama models on RTX)
- Link: https://github.com/block/goose

### Blender addons

**NeXus 2026.1 beta (Insydium, Oct 2 2026)** — Particle-based simulation addon with a unified multi-material solver — think destruction/liquid/fire in one solver.
- Price: paid; subscription from ~$229/yr (NeXus for Blender tier).
- Relevance: 4 (cinematic rather than game-runtime)
- Windows + RTX: yes (GPU-accelerated)
- Link: https://insydium.ltd/

**Export Helper Pro / Blender→Unity 6 FBX Add-on (2026 refresh)** — One-click Unity/Unreal/Godot export presets with correct axis orientation, baked transforms, deform-only rigs, optional animation export.
- Price: ~$15–25 on Gumroad/Blender Market; a free fork (EdyJ) covers the basics.
- Relevance: 9
- Windows + RTX: yes
- Link: https://blenderartists.org/t/addon-blend2unity/695955
- **UPGRADE PATH (Blender→Unity pipeline)**: direct replacement for the manual "apply transforms + export FBX + fix axis" dance; collection-based presets map 1:1 to Unity prefabs with colliders/static flags baked in.

## Headline flags for your tracked workflows

- **ComfyUI**: OmniChar + Qwen-Image-2.1 together are the two upgrades to install this cycle — character identity reuse and native-alpha 2K editing both collapse multi-node sub-chains in a typical game-asset workflow. Meshy 7.1 Ultra 4K via its ComfyUI node is the third.
- **Blender → Unity pipeline**: Export Helper Pro / Blend2Unity 2026 refresh is a real pipeline improvement — collection-based presets map to Unity prefabs with colliders and static flags baked in, which is where the manual dance usually burns time.
- **Enemy AI systems**: Behavior Designer's Sep 11, 2026 update is the clearest upgrade over hand-rolled FSMs or Unity's built-in Behavior Graph when scaling to multiple enemy archetypes. Free alternative: Simple Behavior Tree, if you need to prototype before paying.
