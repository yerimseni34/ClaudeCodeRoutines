# Tool Radar — November 2026

**Window:** 2026-10-23 → 2026-11-23
**Audience:** solo Unity developer on Windows + RTX
**Compiled:** 2026-11-23

## Executive summary

The 30-day window is quiet on genuine net-new releases; most activity is maintenance patches, API tweaks, and listicle reruns. Three in-window picks are the clearest wins for a solo Unity dev:

1. **Blender 5.3** (Nov 10) — DLSS denoising on RTX is a real quality-of-life gain, free.
2. **ComfyUI 0.46.0** (Nov 18) — Video Deflicker, PAN 2, LTX + MiniMax nodes; direct ComfyUI upgrade. *(AMD/DirectML path removed — RTX CUDA path untouched.)*
3. **Behavior Designer Pro 3** (Nov 11) — DOTS-native behavior trees; direct enemy-AI upgrade.

Honorable mentions: **Meshy Unity biped rigging** (Nov 10), **Playtest Analytics** local heatmaps (Oct 27), **Reallusion CC 5.2 + CC Wrap** for AI-mesh → Unity-ready rigs.

## FLAGGED UPGRADES

### (a) ComfyUI workflow

- **ComfyUI 0.46.0 (Nov 18, 2026)** — core upgrade: Video Deflicker, PAN 2, LTX + MiniMax nodes, faster optical flow. **Caveat:** DirectML removed (AMD Windows users affected); **RTX CUDA path fully supported**. Free, open-source. https://docs.comfy.org/changelog
- **Flux 3 Max nodes** (ComfyUI 0.43.0, late Oct) — adjacent; replaces older Flux node packs.

### (b) Blender-to-Unity pipeline

- **Reallusion CC 5.2 + CC Wrap** (Nov 2, 2026 coverage) — not a Blender addon per se, but replaces the "Blender rig-and-cleanup" step for AI-generated meshes with an automated import→rig→animate loop producing Unity-ready FBX. Closest thing to a direct pipeline upgrade in-window.
- **Meshy Unity Plugin** (Nov 10 rigging update) — bypasses Blender entirely for AI mesh → rigged Unity asset with finger bones.
- **Blender 5.3 itself** marginally upgrades the pipeline via stabilized OpenTimelineIO and tighter Vulkan backend parity. Material export to Unity is still a manual rebuild.

### (c) Enemy AI systems

- **Behavior Designer Pro 3** (Nov 11, 2026) — DOTS-native BT authoring. If you're on the original Behavior Designer or NodeCanvas, this is the current successor path.
- **Adaptive Enemy AI Toolkit** (Nov 13, 2026) — smaller, scope unconfirmed; worth evaluating.
- **Unity `com.unity.behavior`** remains at 1.0.16 (May 2026) and is in maintenance mode — stable but not advancing; may break under Unity 6.6 SerializeReference rewrite. Free, official.
- **Behavior Tools For Unity** (3rd-party layering ~200 extra actions on Unity's free Behavior Graph) — date unverified. https://discussions.unity.com/t/released-behavior-tools-for-unity-out-of-the-box-visual-behavior-trees/1722295
