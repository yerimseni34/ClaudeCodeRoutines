# Tool Radar — November 2026

**Window:** tools released or significantly updated in the past ~30 days (early Oct 2026 → 2 Nov 2026).
**Audience:** solo Unity developer on Windows with an RTX GPU.
**Scoring:** 1 = ignore, 5 = situational, 7 = worth a weekend trial, 9+ = reach for immediately.

Sources are web-reported; vendor marketing and comparison blogs dominate dated announcements, so dates and prices below should be re-checked on the vendor's own changelog before adoption. Items without an explicitly confirmed in-window release are included only where the category is otherwise empty, and are marked.

## 🔥 Direct upgrades to flagged workflows

### ComfyUI workflow
- **ComfyUI workflow templates v0.11.92** — cherry-picked ~Oct 20, 2026. Adds HeyGen Voice 1.0, Clarity Crystal Video Upscale, FLUX 3 Max i2v/t2v, and FastH3 OmniRef R2V templates to the bundled set. If your current ComfyUI workflow is older than this, pulling the templates alone is a free upgrade. Free, Windows+RTX yes. https://github.com/Comfy-Org/ComfyUI/pull/17234
- **ComfyUI Frontend 1.10** — new selection tools and workflow template browser. Free, Windows+RTX yes. https://blog.comfy.org/p/comfyui-frontend-110-update-powerful
- **ComfyUI Manager / Nodes 2.0 beta** — Manager split into its own component; Nodes 2.0 is in beta and some common patterns are reportedly broken. Hold until stable. Free, Windows+RTX yes. https://www.runflow.io/blog/comfyui-custom-nodes

### Blender → Unity pipeline
- **Rodin DCC Bridge** (ongoing) — plugins for Blender, Unreal, Unity, Godot. Still the most direct "generate in Rodin, land in Unity" bridge. Freemium. Windows+RTX yes. https://app.cinevva.com/guides/ai-3d-model-generators
- **Meshy Unity plugin** — official plugin, exports to Unity, auto-rig. Pro $20/mo (~1,000 credits) per vendor pages. Windows+RTX yes. https://www.meshy.ai/use-cases/free-game-assets/unity
- **Tintline 2.2** (Oct 28, 2026) — Blender addon, one-click auto shade for low-poly colour atlases. If you ship stylized low-poly to Unity, this cuts a shader-setup step. Paid, Windows+RTX yes. https://www.blendernation.com/
- **Quadify** (Oct 5, 2026) — Blender addon, clean quad retopology. Pairs well with AI-generated meshes before Unity import. Paid, Windows+RTX yes. https://www.blendernation.com/
- **Unity 3D Object Generator** (beta, in Unity AI, Unity 6.0+) — text/image → single-part prop in-engine. Skips the Blender step for simple props but no rig and output needs cleanup. Free with Unity 6, Windows+RTX yes. https://unity.com/blog/unity-ai-3d-object-generator

### Enemy AI systems
- **Unity Behavior package (`com.unity.behavior`)** — Unity 6's official graph-based behavior tree. UI/API still churns between releases; check your Unity version's docs. If you're hand-rolling FSMs, this is the natural upgrade. Free with Unity 6, Windows+RTX yes. https://uhiyama-lab.com/en/notes/unity/unity-behavior-tree-ai/
- **Behavior Tools For Unity** (Asset Store) — built on `com.unity.behavior`, ships ~200 ready-made actions. Older than this window (new-release discount expired June 2026) but still the fastest way to skip boilerplate on top of Unity's official tree. Paid. Windows+RTX yes. https://discussions.unity.com/t/released-behavior-tools-for-unity-out-of-the-box-visual-behavior-trees/1722295

## Honest gaps / what to re-check manually
- No confirmed **October–November 2026 ComfyUI core release**; only template bundle updates were in the public results. Watch https://docs.comfy.org/changelog .
- **Meshy versioning conflict** across sources (Meshy-6 vs 7 vs 7.1). Confirm on docs.meshy.ai/changelog.
- **Enemy AI**: no new in-window Asset Store package surfaced. The upgrade path is `com.unity.behavior` + Behavior Tools, not a new release.
- **Procedural generation**: nothing new worth upgrading to; Promethean / Dungeon Architect / UE PCG still define the space.
- **Voice**: no in-window launch; ElevenLabs + local Chatterbox remain the default stack.

## Recommended trial queue for a solo Unity dev this month
1. Pull **ComfyUI workflow templates v0.11.92** — free, 5 min.
2. Install **Unity CLI + Pipeline** — unlocks headless CI/playtest automation.
3. Try **Cascadeur 2026.2** Animation Layers if you animate characters by hand.
4. If stylized/low-poly: pay for **Tintline 2.2** + **Quadify** — AI-mesh → Unity in one evening.
5. Pick one playtesting tool — **PlayProbe** for link-based, **Antidote** for video-capture.
