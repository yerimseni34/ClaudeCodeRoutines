# Tool Radar — November 2026

**Window:** 2026-10-17 → 2026-11-16 (past 30 days)
**Audience:** solo Unity developer on Windows + RTX GPU
**Flag legend:** 🧩 ComfyUI workflow upgrade · 🅱 Blender→Unity pipeline upgrade · 👾 Enemy AI system upgrade

> **Headline for this month:** Voice NPCs got an official Unity SDK (ElevenAgents), Unity shipped an official **CLI** that replaces most hand-rolled CI scripts, and Opsive dropped a real **enemy-AI** upgrade (Behavior Designer Pro 3.3.4). Local image gen matured (ComfyUI v0.45 + two new AI-3D entries). Procedural/level-design AI was quiet.

## AI-POWERED TOOLS

### 3D asset generation (meshes, textures, environments)

**Meshy 7.1 — rigging update (Nov 10, 2026)** 🅱
- Image/text→3D with auto-rigged characters; new `skeleton_template` and `include_fingers` options, free printability check, one-click AI auto-repair.
- Price: Free tier 200 credits; Pro **$20/mo**, Max **$60/mo**, Unlimited **$120/mo** (annual).
- Relevance: **9/10** — official Unity UPM plugin, Humanoid rig, URP/HDRP.
- Windows + RTX: yes (cloud; Unity plugin).
- https://www.meshy.ai
- 🅱 **Direct upgrade to Blender→Unity character path** — bypasses Blender for riggable character → Unity Humanoid.

**AI Game Dev 0.25.0 — local image gen (~Oct 2026)** 🧩
- Desktop tool that runs SD-class models locally for textures and icons; 0.25.0 adds fully local generation.
- Price: **Free** (BYO compute).
- Relevance: **7/10** — offline/private texture gen without wiring ComfyUI.
- Windows + RTX: yes.
- https://ai-game.dev/blog/local-ai-image-generation-for-games
- 🧩 **Direct upgrade to ComfyUI workflow** — simpler, game-tuned alternative for texture/icon gen.

**Ludo.ai AI Texture Generator (Sept 23, 2026 — just outside, still current)** 🧩
- Seamless tileable PBR textures from prompts, 30+ styles, API + MCP server.
- Price: Free tier + Pro from **~$15/mo**.
- Relevance: **8/10** — MCP means it drops into Claude Code / Cursor automation.
- Windows + RTX: yes (cloud).
- https://ludo.ai
- 🧩 **Direct upgrade to ComfyUI workflow** for tileable textures.

**Microsoft TRELLIS.2 / TRELLIS-4B (current open SOTA)** 🧩
- 4B-param single-image → 3D with PBR GLB output, MIT license.
- Price: **Free** (open weights).
- Relevance: **8/10** — self-host locally; 24 GB VRAM comfortable (4090/5090).
- Windows + RTX: yes (WSL2 viable; Linux primary).
- https://github.com/microsoft/TRELLIS
- 🧩 **Direct upgrade to ComfyUI workflow** — custom nodes available.

**Hunyuan3D 3.0 (Tencent)** —
- Hierarchical 3D-DiT, up to 1536³ geometry, ~3× accuracy of 2.1; 3.0 API-only, 2.1 open-weights.
- Price: Free API trial (20 gens) → Tencent Cloud API pay-as-you-go.
- Relevance: **7/10** — strong quality; EU/UK/KR license restrictions on 2.1.
- Windows + RTX: yes (cloud; 2.1 ~16 GB VRAM local).
- https://3d.hunyuan.tencent.com
