# Tool Radar — September 2026

_Scope: game-dev tools released or significantly updated in the ~30 days preceding 2026‑09‑07. Written for a solo Unity dev on Windows + RTX. Sources listed at the bottom._

## 🚩 Direct upgrades to flagged workflows

- **ComfyUI workflow** → **Hunyuan3D 3.5** (2× faster, up to 8K PBR) and **ComfyUI‑GameAssetsMaker** (Aseprite JSON → IMAGE batch) are drop‑in replacements for the older Hunyuan 2.1 image‑to‑3D and manual sprite splitting steps.
- **Blender‑to‑Unity pipeline** → **EasyMesh Batch Exporter** and **ACT: Game Asset Creation Toolset** now cover LOD hierarchy export, geometry‑node bake, and engine‑aware naming — a straight upgrade over the classic `Blender to Unity` addon for anyone shipping >1 prefab per session.
- **Enemy AI systems** → **BTGraph Complete AI Bundle** (Jun 17, 2026, still the newest entrant on the Asset Store) bundles behavior trees + utility AI + perception in one graph — a direct upgrade over stacking Behavior Designer + a custom utility layer.

## AI‑Powered Tools

### 3D asset generation (meshes, textures, environments)

**Meshy 7** — new image‑to‑3D foundation model with a conversational 3D Agent and native 8K textures (multi‑view up to 4 refs).
- Price: subscription — Free tier; Pro from **$20/mo**, up to $60/mo (model downloads gated to Pro+). 8K texture = 15 credits, 4K = 10.
- Solo Unity relevance: **9/10** (FBX/GLB out, integrates with Unity/Blender/UE)
- Windows + RTX: **yes** (cloud‑hosted; browser‑based)
- Link: https://www.meshy.ai/blog/meshy-7-image-to-3d-geometry-alignment
- Released: **Aug 10, 2026**

**Hunyuan3D 3.5** — Tencent's open image/text‑to‑3D pipeline; 2‑stage mesh + real PBR (albedo/metallic/roughness), described as holeless.
- Price: **free/open** locally; hosted Pro edition ~60‑100 credits, Rapid ~35‑55 credits per gen.
- Solo Unity relevance: **9/10** (best quality open model right now; local run possible)
- Windows + RTX: **yes** (needs decent VRAM for local; RTX 3060+ recommended)
- Link: https://www.3daistudio.com/blog/best-3d-model-generation-apis-2026

**TRELLIS.2 (Microsoft)** — image‑to‑3D w/ PBR from a single photo.
- Price: hosted **15‑55 credits/gen**; open weights via Microsoft.
- Solo Unity relevance: **8/10**
- Windows + RTX: **yes**
- Link: https://www.3daistudio.com/blog/trellis-2-vs-hunyuan-3d-differences-explained

**TripoSR** — ultra‑fast, sub‑second mesh reconstruction, MIT license.

- Solo Unity relevance: **7/10** (quality is behind Hunyuan/TRELLIS but iteration is instant)

## Verdict for a solo Unity dev on Windows + RTX

If you install nothing else this month:
1. **BTGraph Complete AI Bundle** for enemies.
2. **Meshy 7** for on‑demand 3D + Hunyuan3D 3.5 locally via **ComfyUI + comfyui‑ai‑gamedev** for the free path.
3. **Cascadeur 2026.2** for character motion (UE Live Link is a bonus, but even Unity users get root motion + Filament preview).
4. **RenderDoc 1.46** for GPU debugging.
5. **EasyMesh Batch Exporter** if your art pipeline touches Blender daily.
