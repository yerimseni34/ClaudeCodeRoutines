# Tool Radar — September 2026

Coverage window: **2026-08-22 → 2026-09-21** (past 30 days).
Focus: solo Unity indie developer on Windows + RTX GPU.

Relevance = 1–10 for a solo Unity dev shipping a small-to-mid game.
RTX = tested-or-documented to run on Windows with an NVIDIA RTX GPU.

Legend for the direct-upgrade flags called out in the brief:
- **[UPGRADE: ComfyUI]** — improves an existing ComfyUI workflow.
- **[UPGRADE: Blender→Unity]** — improves the Blender-to-Unity FBX/glTF pipeline.

## AI-Powered Tools

### 3D Asset Generation

**Meshy 7.1 "Ultra 4K"** — released 2026-09-10.
- Image-to-3D at 4096³ geometry resolution (2× the prior 2048³), sharper
  textures in the same agent/texturing tool.
- Price: free tier (200 credits/mo); Pro from $20/mo; Max from $60/mo.
- Relevance: **9** — the fastest way for one person to fill a scene with
  bespoke, engine-ready meshes.
- Windows + RTX: **yes** (cloud service, runs in browser; nothing to install).
- Link: https://www.meshy.ai/

**Chaos Cosmos AI 3D (early beta)** — surfaced 2026-09.
- Generates 3D models from a single reference image inside the Chaos Cosmos
  asset library; wraps Tencent's HY 3D and Microsoft's Trellis.2.
- Price: free while in beta for Chaos Cosmos users; requires a Chaos account.
- Relevance: **5** — Chaos ecosystem is V-Ray/arch-viz first, and export to
  Unity-friendly FBX/glTF is not yet a documented path.
- Windows + RTX: **yes** (cloud beta).
- Link: https://www.chaos.com/cosmos

### Character / Animation

*Nothing genuinely new landed in the 30-day window.* Cascadeur, DeepMotion,
Reallusion iClone 8 AI Video Mocap and Zoice are the ones still worth
watching for a solo dev; none of them shipped a headline release since
2026-08-22, so they are not scored here to avoid noise.

### Concept Art / 2D

*No major named release surfaced inside the 30-day window.* Scenario.gg,
Leonardo.ai and Ideogram continue to be the practical shortlist; check back
next month.

### AI-Assisted Coding (beyond Copilot)

**Qwen Code v0.24.0 + Qwen Code Desktop** — released 2026-09-16.
- Open-source terminal coding agent from the Qwen team, now with a first
  desktop client alongside the CLI; agentic multi-file edits, MCP support.
- Price: free / open-source (Apache 2.0); brings your own model key.
- Relevance: **7** — a credible free alternative to Cursor/Claude Code for
  scripting-heavy Unity work; the desktop app closes the "I don't want a
  terminal" gap.
- Windows + RTX: **yes** (Windows build available; local models optional).
- Link: https://github.com/QwenLM/qwen-code

**Cursor 3.11** — shipped 2026-07-10 (just outside the window, but still the
current stable and worth listing since 3.12 has not landed).
- Adds Side Chats and Conversation Search on top of the multi-file agent.
- Price: Hobby free; Pro $20/mo; Business $40/user/mo.
- Relevance: **8** — still the most-polished AI IDE for a solo dev.
- Windows + RTX: **yes**.
- Link: https://cursor.com/

### Procedural Generation / AI Level Design

*No standout release in the 30-day window.* Dungeon Architect (Fab/Unity
Asset Store), Promethean AI and Unity ML-Agents remain the pragmatic picks;
the honest read is that AI level design is still mostly "gameslop" without a
hand-authored pass.

### Voice / Audio Generation

*No major release inside the 30-day window.* ElevenLabs, Fish Audio, Resemble
AI and Replica Studios remain the shortlist. Cheapest usable commercial
license: ElevenLabs Creator at $6/mo.

## Non-AI But Powerful

### Unity Plugins / Packages

**Convai NPC AI Engine v4.6.0** — released 2026-09-07. **[UPGRADE: Enemy AI]**
- Unity package for LLM-driven NPCs: dialog, actions, voice, lip-sync. 4.6.0
  is a routine but recent update; still the most-integrated "drop an AI NPC
  in a scene" option for Unity.
- Price: free tier + paid usage (Convai plans start $9/mo). Runtime API calls
  metered.
- Relevance: **6** — worth it only if your game actually needs conversational
  NPCs; overkill for a scripted-encounter shooter.
- Windows + RTX: **yes** (RTX unused; inference is cloud).
- Link: https://assetstore.unity.com/packages/tools/behavior-ai/npc-ai-engine-dialog-actions-voice-and-lipsync-convai-235621

**Unity Behavior (official)** — actively maintained through the window.
**[UPGRADE: Enemy AI]**
- The successor to "Muse Behavior": Unity's own visual behavior-tree package,
  with blackboard variables and runtime debugging. Free, first-party, no
  Muse subscription needed.
- Price: free (Unity package).
- Relevance: **9** — a solo dev on Unity 6 building enemy AI should try this
  before reaching for a paid asset.
- Windows + RTX: **yes**.
- Link: https://docs.unity3d.com/Packages/com.unity.behavior@latest/

**Free Unity Asset Store drops — September 2026 roundup.**
- Notables inside the window: *Apocalypse 3* (60-asset post-apoc pack),
  a 21-tool Unity utility bundle, a stylized water shader, a runtime
  debugging tool, a distortion VFX pack, a 96-animation dwarf melee pack.
- Price: free.
- Relevance: **7** — free is free; the utility bundle and runtime debug tool
  are the ones a solo dev will get the most out of.
- Windows + RTX: **yes**.
- Link: https://assetstore.unity.com/

### Blender Addons

**Auto-Rig Pro (current maintenance stream)** — no dated release inside the
window, but still the strongest 30-day mention. **[UPGRADE: Blender→Unity]**
- Guided rig + dedicated FBX/glTF exporter that bakes animations and remaps
  bones for Unity/Unreal/Godot. Solves the "my Blender rig lands sideways
  in Unity" tax cleanly.
- Price: $40 one-time on Blender Market.
- Relevance: **9** — pays for itself the first time you skip a manual rebind.
- Windows + RTX: **yes**.
- Link: https://blendermarket.com/products/auto-rig-pro

**Blender_to_Unity (berkecuhadar) — free.** **[UPGRADE: Blender→Unity]**
- One-click FBX export presets with Unity-correct axes, baked transforms,
  deform-only rig option, optional animation export; works on Blender 4.5+.
- Price: free (MIT on GitHub).
- Relevance: **7** — the "just get me out of Blender cleanly" option if you
  can't justify Auto-Rig Pro.
- Windows + RTX: **yes**.
- Link: https://github.com/berkecuhadar/Blender_to_Unity

### Performance Profiling / Optimization

**Unity 6 Profiler — updated docs + Highlights module.**
- The Highlights module now flags where you're missing your target frame
  time directly in the Profiler; the "Ultimate Guide to Profiling (Unity 6)"
  e-book was refreshed in the window.
- Price: free (bundled with Unity 6).
- Relevance: **10** — cheapest performance win a solo dev has.
- Windows + RTX: **yes**.
- Link: https://unity.com/features/profiling

*No standout release in the 30-day window for solo devs.* Nothing worth

### Playtesting / Analytics

**Playtester** — reached its 600-games / 40k-visitors milestone this window.
- Free playtest-discovery platform; devs list an alpha/beta and get real
  players from Steam/PS/Xbox audiences.
- Price: free.
- Relevance: **8** — free, low-friction, and specifically indie-shaped;
  useful the moment you have a playable build.
- Windows + RTX: **yes** (web).
- Link: https://playtester.io/

**GameAnalytics** — still the pragmatic default for a solo dev.
- Free game analytics SDK for Unity: sessions, events, retention, funnels.
- Price: free up to 100k MAU; paid above.
- Relevance: **8**.
- Windows + RTX: **yes**.
- Link: https://gameanalytics.com/

## Direct-Upgrade Callouts

### ComfyUI workflow upgrades (all inside the 30-day window)
- **Inpaint Canvas custom node** (2026-09-05) — layered inpainting with
  SAM-assisted picking and PSD export. Replaces the ad-hoc mask-node chains
  people usually cobble together. [ComfyUI changelog](https://docs.comfy.org/changelog)
- **Sparse Attention core node + memory compiler** (2026-09-06) — three
  backends for MiniMax H3; cuts VRAM waste and speeds long H3 runs.
  Meaningful for an RTX box doing video-length generations. [ComfyUI changelog](https://docs.comfy.org/changelog)
- **MiniMax H3 Max option + TRELLIS remesh memory drop** (2026-09-02) —
  better 3D-preview stability in cloud and lower memory for TRELLIS.
