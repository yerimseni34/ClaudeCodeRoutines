## AI-powered tools

### 3D asset generation (meshes, textures, environments)

**Meshy 7** — image-to-3D foundation model with better geometry alignment (81.0% overall proportion, beats Tripo 3.1 / Rodin 2.5).
- Released: **Aug 10, 2026**
- Price: **Subscription** — free tier w/ credits; paid tiers from ~$20/mo; per-model cost ≈ $0.60
- Relevance: **9/10**
- RTX/Win: **yes** (browser + cloud; local export to FBX/GLB into Unity)
- Link: <https://www.meshy.ai/blog/meshy-7-image-to-3d-geometry-alignment>

**Hunyuan3D 2.1 ComfyUI nodes** 🔺 — local text/image → textured 3D mesh, drops straight into a ComfyUI graph.
- Status: actively updated through Aug–Sep 2026
- Price: **Free** (open source)
- Relevance: **8/10** for anyone already on ComfyUI
- RTX/Win: **yes** (needs ~12 GB VRAM comfortably; RTX 4070+ recommended)
- Link: <https://github.com/mattwilliamson/comfyui-ai-gamedev>

## What I'd act on first (solo Unity dev, Windows + RTX)

1. **Try TriSync** on a throwaway branch — the FBX round-trip is the biggest daily-annoyance cost in the Blender→Unity loop, and this is the first tool in a long time that credibly kills it. Verify it holds up on your rig setup before committing.
2. **Adopt Unity Behavior** (free, first-party) for enemy AI unless you're already deep in Behavior Designer.
3. **Install the Unity CLI + Pipeline package** even if you don't wire it into CI yet — the ability to drive the Editor headlessly is worth having in your toolbox.
4. **Update your ComfyUI** graph to use the Sparse Attention Node + Comfy Compiler if you run long H3 jobs; add MiniMax H3 RefMods if character consistency matters. Consider Hunyuan3D 2.1 + Ubisoft CHORD nodes for a fully-local 3D + PBR pipeline.
5. **Try Unity AI Beta** ($10/mo, 14-day free trial) alongside whatever agent you already use — the in-editor project context is a real differentiator.
