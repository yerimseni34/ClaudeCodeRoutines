# Tool Radar — September 2026

Scan window: 2026-08-28 → 2026-09-28. Target: solo Unity developer on Windows with RTX GPU.

Relevance scores (1–10) weight: solo-friendliness, Unity fit, RTX-Windows viability, whether it replaces or improves something in a typical indie pipeline.

Flagged upgrades to watch — details in the last section:

- **ComfyUI workflow:** MiniMax H3 Sparse Attention core node + memory compiler (Sep 6); Inpaint Canvas custom node (Sep 5); Recraft V4 Styles / Styles Pro (Sep 4).
- **Blender → Unity pipeline:** Unity Bridge Exporter (one-click preset pipeline); Super Duper Batch Exporter (auto-LOD on export, Blender 5.2-compatible).
- **Enemy AI systems:** Unity's own free `Unity Behavior` package (successor to Muse Behavior) is now the default recommendation over paid trees; "Behavior Tools For Unity" (Jun 2026) still worth a look for visual authoring.

## AI-Powered Tools

### 3D asset generation

**Meshy 7.1** — Ultra 4K image-to-3D geometry mode (4096³ voxel resolution, up to ~80M raw tris before decimation). Released **2026-09-10**.
- One sentence: Image/text → game-ready mesh with PBR textures, auto-rig and Unity/Unreal export in one browser tool.
- Price: Free tier (limited credits); paid from **$20/mo** (Pro) up to Enterprise; commercial license on paid tiers.
- Solo-Unity relevance: **9/10** — best all-round pipeline for props and stylized characters.
- Windows/RTX: **Yes** (cloud rendered; nothing runs locally on your GPU).
- Link: https://www.meshy.ai

**Chaos Cosmos AI generation** — Added AI image-to-3D in Chaos Cosmos library (backed by Tencent HY 3D and Microsoft Trellis.2). Announced early Sep 2026.
- One sentence: Generate a 3D model from one reference image directly inside the Cosmos asset browser.
- Price: Free for Chaos users; ships with V-Ray / Chaos ecosystem (V-Ray Solo ~$44.90/mo).
- Solo-Unity relevance: **4/10** — mostly aimed at archviz; only useful if you already own V-Ray.
- Windows/RTX: **Yes**.
- Link: https://www.chaos.com/cosmos

**Autodesk Wonder 3D** — Newer AI-native 3D DCC entrant highlighted in the Sep 2026 CG Channel roundup.
- One sentence: Autodesk's answer to Meshy/Rodin, tied into the Autodesk stack.
- Price: Autodesk subscription; pricing not published for indies.
- Solo-Unity relevance: **3/10** — Autodesk subscription cost kills it for most solo devs.
- Windows/RTX: **Yes** (Windows-first).
- Link: https://www.cgchannel.com/2026/09/new-cg-software-you-may-have-missed-7-september-2026/

**TRELLIS.2 / Hunyuan3D / SPAR3D / SAM 3D** — Open-weight models available to run locally through ComfyUI 3D nodes; steady checkpoint churn through Sep 2026.
- One sentence: Free image-to-3D models you can host yourself on an RTX card.
- Price: **Free** (open weights, non-commercial or permissive depending on model — check each license).
- Solo-Unity relevance: **7/10** — worth the setup if you already run ComfyUI locally.
- Windows/RTX: **Yes** (12+ GB VRAM recommended for TRELLIS.2 / Hunyuan3D).

## Flagged upgrades

### ComfyUI workflow

- **MiniMax H3 Sparse Attention core node + memory compiler** (2026-09-06) — Three attention backends and reduced VRAM waste for long H3 runs. Direct workflow win on RTX cards where VRAM is the bottleneck. https://docs.comfy.org/changelog
- **Inpaint Canvas custom node** (2026-09-05) — Turns ComfyUI into a layered paint app: SAM-assisted selections, inpaint round-trips, filter layers, PSD export. If your ComfyUI workflow was "generate → open in Photoshop → back into ComfyUI," this collapses the loop.
- **Recraft V4 Styles / Styles Pro nodes** (2026-09-04) — Custom-trained style + style reference workflow for consistent look. Useful if you're building a game's art bible.
- **4K video generation for ByteDance 2, Veo, Kling nodes; Veo 3 Lite** — Trailer/cutscene generation now hits 4K natively.

### Blender → Unity pipeline

Two direct upgrades this month over the standard "export FBX and pray" approach:

- **Super Duper Batch Exporter** — Auto-LOD via Decimate on export. Unity picks up LOD groups automatically.
- **Unity Bridge Exporter (Superhive)** — Correct axis + baked transforms + deform-only rigs in one click; Mixamo-compatible presets.

Pair either with Unity 6's improved Blender auto-import for a nearly-zero-config pipeline.

### Enemy AI systems

The big story is **Unity Behavior** — Unity's official successor to Muse Behavior — is now the free default: visual graph editor, blackboard variables, runtime debugging. For most solo devs it replaces paid packages like AI Tree or Advanced Enemy AI. The only reasons to look at a paid alternative in Sep 2026:

- **Behavior Tools For Unity** (Jun 2026) — If you want an even more visually-focused authoring UX than Unity Behavior's.
- **AI Tree** (Renowned Games) — Long-standing paid option; still a fine choice if you already own it, but no longer a clear upgrade over first-party.
