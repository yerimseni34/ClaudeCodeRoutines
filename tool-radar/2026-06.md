# Tool Radar — June 2026

Window: ~May 22 – June 22, 2026. Focus: solo Unity dev on Windows + RTX.

## TL;DR — upgrade candidates

- **ComfyUI workflow upgrade**: Meshy 3D Agent Beta (Jun 4) + Hunyuan 3D 3.0 Parts Decomposition Partner Nodes — both ship in core, both export game-ready GLB/FBX. Drop-in replacement for hand-wired text-to-3D graphs.
- **Blender → Unity pipeline upgrade**: Blender 5.2 LTS Beta (Jun 5) rewrote the FBX binary path for skeletal meshes. If you've been fighting bone-hierarchy import bugs, this is the fix.
- **Enemy AI upgrade**: Utility Intelligence GO v3 — measured ~4h to author vs 8h (BT) / 12h (GOAP) for equivalent agents, and stays under frame budget at 100+ agents where GOAP spikes to 28.7ms.

## AI-powered tools

### 3D asset generation

**Meshy 3D Agent Beta** — *flagged: ComfyUI upgrade*
- Conversational chat-to-3D agent: brainstorm → batch concepts → mesh → PBR texture → auto-rig → GLB/FBX in one thread.
- Price: free tier + paid Meshy plans (Pro from ~$20/mo, no separate Agent fee during beta).
- Relevance: **9/10** — covers the whole hero-prop pipeline, Unity export native.
- Windows + RTX: yes (cloud-rendered; client is browser/desktop).
- https://www.meshy.ai/features/3d-agent
- Launch (Jun 4, 2026): https://www.prnewswire.com/news-releases/meshy-launches-3d-agent-beta-the-worlds-first-ai-agent-for-3d-creation-302790052.html

**Hunyuan 3D 3.0 in ComfyUI (Partner Node update)** — *flagged: ComfyUI upgrade*
- Adds 3D Parts Decomposition — splits a generated asset into editable sub-meshes for modular swaps/animation prep.
- Price: free (open weights; runs locally).
- Relevance: **8/10** — local, no API spend, and the parts split is what was missing for game-ready outputs.
- Windows + RTX: yes (24GB ideal; works on 12GB with quantized weights).
- https://blog.comfy.org/p/hunyuan-3d-30-in-comfyui-state-of

### Character / animation AI

**Cascadeur 2026.1** (Nekki, late-April → patches through May)
- AI-assisted keyframe animator; this release adds **Root Motion** (AI-generated in-betweens with reference style), Filament viewport renderer, and a rebuilt **Unreal Live Link** plugin.
- Price: free tier (commercial up to $100k rev); Pro $25/mo; Live Link is paid-tier only.
- Relevance: **7/10** — useful even without UE; root motion solves a real indie pain point.
- Windows + RTX: yes.
- https://cascadeur.com/

**Krikey AI** (active updates through 2026)
- Video-to-motion + text-to-animation for 3D avatars; exports FBX to Unity/Mixamo-compatible rigs.
- Price: free tier; Pro from $15/mo.
- Relevance: **6/10** — webcam mocap path is solid for prototyping; quality still trails hand-keyed.
- Windows + RTX: yes (cloud).
- https://www.krikey.ai/

### Concept art / 2D assets

Nothing in the 30-day window worth flagging over the existing SDXL/FLUX/Qwen-Image-Edit-2511 stack. Consistent Character Creator 3.8 (ComfyUI workflow on Qwen-Image-Edit-2511) is the current sweet spot for sprite/portrait consistency.
- https://www.runcomfy.com/comfyui-workflows/consistent-character-creator-3-8-in-comfyui-hyperrealistic-consistent-ai-characters

### AI-assisted coding (beyond Copilot)

**Cursor Composer 2.5** (released May 18, 2026)
- In-house agent model: 62 on Artificial Analysis Coding Agent Index. Multi-file edits, terminal, iterative debug.
- Price: $0.50/M input, $2.50/M output (fast variant $3/$15); included in Cursor Pro $20/mo.
- Relevance: **8/10** — cheap-per-token agent good for C# scripts and editor tooling.
- Windows + RTX: yes (cloud model; client native).
- https://cursor.com/changelog/composer-2-5

**Google Antigravity 2.0** (released May 19, 2026)
- Agentic IDE with dynamic subagents, scheduled background tasks, Go-based CLI, public SDK, Gemini 3.5 Flash default.
- Price: free tier + paid plans via Google AI ($20/mo equivalent).
- Relevance: **6/10** — promising but Unity/C# ecosystem support still thinner than Cursor's.
- Windows + RTX: yes.
- https://lushbinary.com/blog/ai-coding-agents-comparison-cursor-windsurf-claude-copilot-kiro-2026/

### Procedural / AI level design

**AI Level Designer** (TaaroBravo, open source, recent commits in window)
- Unity 6 editor extension: natural-language prompt → validated, playable scene. Supports OpenAI and local Ollama backends.
- Price: free (MIT).
- Relevance: **7/10** — local Ollama path means no API bill for greyboxing.
- Windows + RTX: yes (Ollama runs on RTX directly).
- https://github.com/TaaroBravo/ai-powered-level-designer

### Voice / audio generation

**NVIDIA ACE TTS** (debuted GDC 2026, March)
- First production-grade on-device TTS — no cloud roundtrip. Targets NPC dialog at runtime.
- Price: free SDK for devs; royalty model TBC for commercial.
- Relevance: **7/10** — only if you want runtime barks; for pre-baked dialog, ElevenLabs/Resemble still win on quality.
- Windows + RTX: yes (designed for RTX).
- https://blog.imseankim.com/gdc-2026-ai-game-development-npcs-procedural-content-voice-acting/

**Resemble Chatterbox v1.0.0**
- 350M-param zero-shot voice cloning from a short sample.
- Price: open weights (free local); hosted from $5/mo.
- Relevance: **7/10** — strong for prototyping NPC voices before licensing real VO.
- Windows + RTX: yes.
- https://elevenlabs.io/use-cases/gaming (comparison context)

## Non-AI but powerful

### Unity Asset Store / plugins

**Utility Intelligence GO v3** — *flagged: enemy AI upgrade*
- Utility-AI framework for GameObject projects. Modern alternative to BT/FSM/GOAP; scores actions rather than evaluating conditional chains.
- Price: paid (Asset Store, ~$40–60).
- Relevance: **9/10** — measurably faster to author and cheaper at scale than BT/GOAP for enemy behavior.
- Windows + RTX: yes (pure CPU; engine-agnostic).
- https://uintel-go.utilityworlds.com/

**Procedural Building Builder** (released Apr 30, 2026 — just outside the window but worth noting)
- Free runtime procedural building generator.
- Price: free.
- Relevance: **6/10**.
- Windows + RTX: yes.
- https://assetstore.unity.com/packages/tools/level-design/procedural-building-builder-373346

**Procedural City Generator** (recent Asset Store release)
- Block-based city layout for backgrounds / open-world greyboxing.
- Price: paid (~$30).
- Relevance: **5/10** — niche.
- Windows + RTX: yes.
- https://assetstore.unity.com/packages/tools/level-design/procedural-city-generator-330140

### Blender addons

**Blender 5.2 LTS Beta** (Jun 5, 2026) — *flagged: Blender→Unity upgrade*
- Rewritten FBX binary export path for skeletal meshes with complex bone hierarchies. Dynamic Cloth/Hair node sim. Remote Asset Libraries. Loop Tools in core (C++).
- Price: free.
- Relevance: **9/10** — the FBX fix alone is worth upgrading for any rigged-character workflow.
- Windows + RTX: yes.
- https://developer.blender.org/docs/release_notes/5.2/

**Super Duper Batch Exporter** (active in Blender Extensions platform)
- Batch DAE/USD/OBJ/FBX/glTF with per-format options (FBX gets auto-LOD via decimate on export).
- Price: free.
- Relevance: **7/10** — pairs well with 5.2's new FBX path.
- Windows + RTX: yes.
- https://extensions.blender.org/add-ons/superduperbatchexporter/

### Profiling / optimization

### Pipeline automation

**Houdini Engine for Unity** (still free for commercial)
- Procedural HDA assets loaded into Unity. Mature, not new, but the "now free" status hasn't changed and many indies still don't know.
- Price: free runtime; Houdini Indie $269/yr for authoring.
- Relevance: **7/10** for anyone with assets to mass-generate.
- Windows + RTX: yes.
- https://www.sidefx.com/community/houdini-engine-for-unreal-and-unity/

- Windows + RTX: n/a.
