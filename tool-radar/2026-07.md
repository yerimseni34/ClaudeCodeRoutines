# Tool Radar — 2026-07

Game dev tools released or significantly updated in the ~30 days ending 2026-07-13, scored for a solo Unity developer on Windows / RTX. Prices are best-effort as of publication.

## TL;DR — Direct upgrades to flagged workflows

- **ComfyUI workflow** → Ubisoft **CHORD** ComfyUI nodes (AAA-grade texture → full PBR set) and **Hunyuan 3D 2.5** for text/image→mesh at 1024-res geometry. Both are locally runnable on an RTX card. See "AI-Powered Tools" below.
- **Blender → Unity pipeline** → **Export Helper Pro** (free, Blender 5-native, one-panel FBX/glTF/OBJ export with Unity coordinate handling) and **Super Duper Batch Exporter v2.8.2** (batch/one-click). See "Non-AI But Powerful".
- **Enemy AI systems** → **Utility Intelligence (ECS) v-Apr-19** for a DOTS-friendly utility+FSM+BT hybrid, plus Unity 6's built-in **Behavior Graph** package as the new default. See "Non-AI But Powerful".

## AI-Powered Tools

### 3D asset generation (meshes, textures, environments)

- **Hunyuan 3D 2.5 (Tencent)** — Text/image → high-fidelity mesh with PBR textures; geometric resolution bumped to 1024, 8–20s per model on RTX 4090, weights and code open on GitHub. Latest 2.5 line ships throughout Q2/Q3 2026 with continued texture-model updates.
  - **Price:** Free (open weights, community license); Tencent Cloud API metered.
  - **Solo-Unity relevance:** 9/10 — best open text-to-3D you can run locally today.
  - **Windows + RTX:** Yes (RTX 4090 recommended; ~24 GB VRAM peak, quantized configs run on 12 GB).
  - **Link:** https://github.com/Tencent-Hunyuan/Hunyuan3D-2  •  paper: https://arxiv.org/abs/2506.16504
  - **Flag:** DIRECT UPGRADE to ComfyUI workflows — swap in for older Hunyuan/TripoSR nodes.

- **Meshy AI (v5 line, June 2026 updates)** — Text/image → rigged, PBR-textured mesh with FBX/GLB/USD export; browser + Unity plugin. Late-June refresh added better auto-retopo and animation preview.
  - **Price:** Free tier (200 credits/mo); Pro $20/mo; Studio $60/mo; Enterprise custom.
  - **Solo-Unity relevance:** 9/10 — least-friction end-to-end pipeline for props.
  - **Windows + RTX:** Yes (cloud; browser is enough).
  - **Link:** https://www.meshy.ai/

- **Unity AI 3D Object Generator (in-editor, Muse extension)** — Generate props/environment meshes from text or image directly inside the Editor; imports as prefab, respects project material settings.
  - **Price:** Bundled with Unity Muse subscription — $30/mo per seat (7-day trial).
  - **Solo-Unity relevance:** 8/10 for prototyping; 6/10 for shipped hero assets.
  - **Windows + RTX:** Yes (cloud generation, any GPU).
  - **Link:** https://unity.com/blog/unity-ai-3d-object-generator

## Bonus — direct upgrades called out separately

### ComfyUI workflow upgrades (past 30 days)

- **Ubisoft CHORD ComfyUI nodes** — Three-stage pipeline (texture generation → PBR estimation → 2K/4K upscale). Research-only license, but node code is Apache-2.0-friendly for internal use. **Windows + RTX: Yes.** https://github.com/ubisoft/ComfyUI-Chord
- **ComfyUI Desktop app (GA 2026)** — One-click install on Windows/macOS with model/node manager. Free. https://docs.comfy.org/
- **CHORD + Hunyuan 3D 2.5 combo** replaces the older FLUX-tileable-LoRA → separate normal/roughness extraction stacks for material work.

### Blender → Unity pipeline upgrades (past 30 days)

- **Export Helper Pro** (Blender-5-native, free) and **Super Duper Batch Exporter v2.8.2** together cover ~95% of solo-dev export needs without hand-editing Unity import settings.
- Pair with **PROTO Game Asset Tools v2.2.0** for the pre-export cleanup step (vertex colors, driver bakes, action-per-frame export).

### Enemy AI system upgrades (past 30 days)

- **Utility Intelligence (ECS)** for DOTS projects and **Unity 6 Behavior Graph** for GameObject projects — between them they cover both current-gen Unity architectures without a third-party runtime lock-in.
- Pair with **Inworld AI** if you need LLM-driven dialog on top of the tactical brain.
