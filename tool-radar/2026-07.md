# Tool Radar — 2026-07

Scope: tools released or significantly updated in roughly the last 30 days
(early June through early July 2026), scored for a **solo Unity developer on
Windows with an RTX GPU**.

Legend:
- **Relevance** — 1 (niche) to 10 (must-look) for a solo Unity dev.
- **RTX/Win** — yes / no / unknown.
- 🔺 **Direct upgrade** flag for: ComfyUI workflow, Blender→Unity pipeline,
  or enemy AI systems.

---

## Executive summary

Three things are worth your time this month if you skim nothing else:

1. **Hunyuan3D PolyGen 1.5 → 3.5 line** now hits quad-dominant topology,
   ~60s generation, and 4K–8K PBR — the first AI mesh output that isn't
   a retopo disaster. Direct ComfyUI-workflow upgrade.
2. **ComfyUI 0.27.0** (June 30, 2026) adds int8 quantized model support,
   a Seed Node, Advanced Krea 2 model-merging, Bounding Box Canvas and
   ConditioningMultiply — noticeable speed/quality bump on RTX cards.
3. **Unity AI Beta 2026** (in-editor agent) + the maturing MCP bridges
   (CoplayDev, IvanMurzak, CoderGamester) mean Cursor/Claude Code can now
   drive Unity directly. This is the biggest workflow shift of the month.

Nothing genuinely new landed for enemy-AI (behavior trees); Unity's own
`com.unity.behavior` graph package continues to iterate but no headline
release in this window.

## AI-powered tools

### 3D asset generation

#### 🔺 Hunyuan3D PolyGen 1.5 / 3.5 (Tencent)
- **What**: Autoregressive mesh generator producing quad-dominant topology,
  50k–1.5M polys, 4K PBR (8K in 3.5), under-60s generation.
- **Price**: Open-source weights (Apache-style, non-commercial for some
  variants — check the model card); hosted via 3DAI Studio, Scenario, etc.
- **Relevance**: 9/10 — first AI 3D output that actually retopos cleanly
  for Unity import.
- **RTX/Win**: Yes (recommended 24GB VRAM for the full model; distilled
  variants run on 12GB).
- **Link**: <https://github.com/Tencent-Hunyuan/Hunyuan3D-2>
- **🔺 Direct upgrade to ComfyUI workflow** — replaces older TripoSR /
  Hunyuan3D 1.0 nodes with dramatically better topology.

#### Tripo 3.0
- **What**: Text/image → 3D with up to 2M polys, sculpture-level detail,
  new style transforms.
- **Price**: Free tier (limited credits); Pro from $20/mo; Studio $50/mo.
- **Relevance**: 8/10 — best "just works in browser" option; slower than
  v2.5 (~100s vs 25–30s) but higher fidelity.
- **RTX/Win**: N/A — cloud only.
- **Link**: <https://www.tripo3d.ai/>

#### Meshy (2026 workflow update reviewed June 2026)
- **What**: Text/image→3D + PBR texturing + auto-rig + retopo in one
  browser pipeline.
- **Price**: Free 200 credits/mo; Pro $20/mo; Max $60/mo; Enterprise custom.
- **Relevance**: 8/10 — end-to-end pipeline, no local install; good for
  prototypes and NPC filler.
- **RTX/Win**: N/A — cloud.
- **Link**: <https://www.meshy.ai/>

### Character / animation AI

#### Cascadeur 2025.1 (still current) + Rokoko integration webinar (Jun 2026)
- **What**: AI-assisted physics-based keyframe animation with AutoPosing +
  AutoPhysics; recent focus on Rokoko/Move.ai/Mixamo mocap cleanup.
- **Price**: Free (Basic, up to non-commercial + <$100k revenue); Pro
  $299/yr; Business $1,099/yr.
- **Relevance**: 8/10 — the mocap cleanup workflow is a real time-saver
  even without a Rokoko suit.
- **RTX/Win**: Yes.
- **Link**: <https://cascadeur.com/>

### Concept art / 2D asset generation

#### Krea 2 + Recraft V4 (via Krea's node workflows, updated June 2026)
- **What**: Krea 2 for early exploration + Recraft V4 for production-consistent
  outputs (saved styles, vector out). New node-based Krea "workflows"
  target pattern/texture generation for games.
- **Price**: Krea Free tier; Basic $10/mo; Pro $35/mo; Max $60/mo. Recraft
  V4 is included in Krea Pro credits.
- **Relevance**: 7/10 — solid concept + texture workflow; the vector/SVG
  path from Recraft is useful for UI.
- **RTX/Win**: N/A — cloud.
- **Link**: <https://www.krea.ai/>

### AI-assisted coding (beyond Copilot)

#### 🔺 Unity AI Beta 2026 (in-editor agent)
- **What**: First-party agent inside the Unity Editor with full scene/asset
  context, credit-billed.
- **Price**: $10/mo Unity Personal (14-day trial); included in Pro,
  Enterprise, Industry.
- **Relevance**: 9/10 — this is the direction Unity is going; worth trialing
  even if you stay on MCP bridges.
- **RTX/Win**: Yes.
- **Link**: <https://unity.com/features/ai>

#### CoplayDev Unity-MCP (MIT, active development)
- **What**: MCP bridge letting Cursor / Claude Code / Windsurf / Copilot
  Chat / Cline drive the Unity Editor (scenes, assets, scripts) over
  localhost.
- **Price**: Free (MIT). You pay whatever your agent subscription costs.
- **Relevance**: 10/10 — biggest workflow shift this month for solo devs.
- **RTX/Win**: Yes.
- **Link**: <https://github.com/CoplayDev/unity-mcp>

#### IvanMurzak Unity-MCP
- **What**: Similar bridge, focus on "any C# method becomes a tool with
  one line"; ships a CLI for setup.
- **Price**: Free.
- **Relevance**: 8/10 — pick this over CoplayDev if you want to expose
  project-specific tools to the agent.
- **RTX/Win**: Yes.
- **Link**: <https://github.com/IvanMurzak/Unity-MCP>

#### CoderGamester mcp-unity
- **What**: Third MCP bridge, targets Cursor / Codex / Antigravity /
  OpenCode in addition to the usual suspects.
- **Price**: Free.
- **Relevance**: 7/10 — pick by IDE fit; overlaps heavily with the above.
- **RTX/Win**: Yes.
- **Link**: <https://github.com/CoderGamester/mcp-unity>

### Procedural generation / AI level design

#### PCG Graph (Unity, released Feb 2026, active updates)
- **What**: Node-based procedural placement (Shader Graph, but for scattering
  and object generation).
- **Price**: Paid on Asset Store (~$40 tier; verify current listing).
- **Relevance**: 8/10 — closest thing to Unreal PCG for Unity right now.
- **RTX/Win**: Yes.
- **Link**: <https://discussions.unity.com/t/released-pcg-graph-visual-node-based-procedural-generation/1707098>

#### Procedural Toolkit (updated June 27, 2026)
- **What**: Long-lived open-source PCG library (terrain, cities, dungeons,
  planets); code-first.
- **Price**: Free (MIT).
- **Relevance**: 6/10 — great if you're comfortable in code; skip if you
  wanted a node UI.
- **RTX/Win**: Yes.
- **Link**: <https://github.com/Syomus/ProceduralToolkit>

### Voice / audio generation

#### Resemble Chatterbox v1.0.0
- **What**: 350M-param open model doing zero-shot voice cloning from a
  short sample; local inference.
- **Price**: Model weights free (MIT-ish); hosted API paid.
- **Relevance**: 8/10 — first competitive **local** cloning option for
  indie budgets.
- **RTX/Win**: Yes (runs on 8–12GB VRAM).
- **Link**: <https://www.resemble.ai/chatterbox/>

#### NVIDIA ACE on-device TTS (debuted GDC 2026)
- **What**: On-device text-to-speech for NPCs, no cloud roundtrip; pairs
  with Riva v1.1 ASR for full voice loops.
- **Price**: Free SDK; commercial NVIDIA licensing terms apply.
- **Relevance**: 7/10 — only relevant if you're building live-voice NPCs;
  overkill for scripted VO.
- **RTX/Win**: Yes (designed for it — NVIDIA-first).
- **Link**: <https://developer.nvidia.com/ace>

#### ElevenLabs (game voice library expanded 2026)
- **What**: Cloud TTS with a game-oriented voice library.
- **Price**: Free (10k chars/mo); Starter $5/mo; Creator $22/mo; Pro $99/mo.
- **Relevance**: 7/10 — still the fastest path from script to shipped VO.
- **RTX/Win**: N/A — cloud.
- **Link**: <https://elevenlabs.io/voice-library/voices-for-video-games>

## Direct upgrades — do these this week

1. **Update ComfyUI to 0.27.0** — free, 15 minutes, real quality/speed gain.
2. **Try Hunyuan3D PolyGen (3.5 if you can access it)** — the topology
   improvement makes AI meshes actually usable in a Unity pipeline for
   the first time.
3. **Install a Unity MCP bridge** (CoplayDev is the safest first pick) and
   point Cursor or Claude Code at it. This is the single largest workflow
   change on the list.
4. **Refresh Auto-Rig Pro to v3.78.14** — Blender 5.1 support + Unity FBX
   export tweaks. Skip if you don't do character work.

## Nothing genuinely new this month

- **Enemy AI / behavior trees**: no new headline release. Existing options
  (Unity's `com.unity.behavior`, AI Tree, Behavior Designer, Fluid BT) are
  still the best picks. If you're evaluating for the first time, start
  with `com.unity.behavior` — first-party is winning here.
