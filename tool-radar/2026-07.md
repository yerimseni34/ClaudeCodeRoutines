# Tool Radar — July 2026

Research window: 2026-06-20 → 2026-07-20. Focus: tools relevant to a solo Unity developer on Windows with an RTX GPU.

Legend:
- **Relevance** = solo-Unity-dev score, 1–10.
- **Win/RTX** = works on Windows with an RTX GPU (yes / no / unknown).
- Rows tagged **[UPGRADE]** are direct upgrade candidates to one of the flagged workflows (ComfyUI, Blender→Unity, enemy AI).

## Executive summary

- Biggest genuinely fresh releases in the 30-day window: **GPT-5.6 (GA 2026-07-09)** driving new agent modes in Copilot / Cursor / Claude Code, **PCG Graph** procedural content generator (Unity Asset Store, July 2026), and **AI LEVEL SCATTER** (Unity Asset Store, updated June 2026). The **Ubisoft CHORD** ComfyUI node set (open-sourced Dec 2025) has continued gaining momentum and is the highest-value ComfyUI upgrade a solo dev can drop into an existing texture workflow this month.
- The AI 3D-asset trio (Meshy 6, Tripo, Rodin Gen-2.5) is now good enough for prop / blockout / secondary meshes; still not ready for hero characters that need clean animation topology.
- For enemy AI, no killer new plugin dropped this month — **Enemy & NPC AI** (SuperHorizonstudios, Jan 2026) and the maintained **AI Tree** remain the strongest packaged options.

## Upgrade highlights (flagged workflows)

1. **ComfyUI workflow →** add **Ubisoft CHORD + ComfyUI-Chord** for end-to-end AI PBR-material generation (tileable albedo/normal/roughness/metallic in one graph). Research license — fine for personal / iteration work; check terms before shipping in commercial builds.
2. **Blender → Unity pipeline →** switch to **Export Helper Pro** (one-click multi-target export presets with an in-N-panel UI) plus **Asset Optimizer** for LOD/decimation batch passes. Order-of-magnitude fewer clicks than the stock FBX exporter.
3. **Enemy AI systems →** if you're still hand-rolling state machines, **AI Tree** (mature, actively maintained) or **Enemy & NPC AI** (packaged, published Jan 2026) both cut days of scaffolding. AI Tree is the better choice if you want to extend nodes yourself.

## Not-yet-ready / caveats

- AI-generated hero character meshes still need heavy topology cleanup — treat all text-to-3D output as blockout/prop, not final hero art.
- ComfyUI CHORD is under a **research-only** license — do not ship materials produced with it in a commercial title without confirming licensing.
- Autodesk Wonder 3D is powerful but priced/tooled for studios, not solo devs.
