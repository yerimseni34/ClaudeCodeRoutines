# Tool Radar — August 2026

_Coverage window: 2026-07-25 → 2026-08-24 (last 30 days). Focus: solo Unity dev on Windows / RTX._

Relevance scores are calibrated for a **solo Unity developer** — a tool that's brilliant for a AAA pipeline can still score low here if setup is heavy or it doesn't fit a one-person workflow.

## AI-Powered

### 3D asset generation

**Meshy 7** — released 2026-08-10
- **What:** Image-to-3D foundation model; multiview upgrade in August accepts up to 4 views and generates native 2K/4K/8K base-color textures.
- **Price:** Free (100 credits/mo, CC BY 4.0 output) · Pro $20/mo (1,000 credits, private assets, API) · Premium $40/mo · Ultra $100/mo.
- **Relevance (solo Unity dev): 9/10** — the workhorse concept→game-ready mesh tool this month. Multiview output closes the "back-of-the-model is mush" gap that killed earlier versions for game work.
- **Windows + RTX?** Yes (cloud, browser). No local GPU needed.
- **Link:** https://www.meshy.ai/

**Tripo 3.1 (in ComfyUI)** — Partner node, current
- **What:** High-detail image/text-to-3D, tuned for hero assets with denser geometry.
- **Price:** Free ComfyUI node; Tripo API credits sold separately (starts around $0/free trial → paid credit packs).
- **Relevance: 8/10** — best-in-class when Meshy's density isn't enough; runs inside your existing Comfy graph.
- **Windows + RTX?** Yes (Comfy node calls hosted API; local GPU not required for generation).
- **Link:** https://blog.comfy.org/p/tripo-31-in-comfyui

**Hunyuan 3D 3.0 (in ComfyUI)** — Partner node, current
- **What:** Tencent's open-weight text/image/sketch → 3D, updated to 3.0 with better topology and PBR texturing.
- **Price:** Free (open weights) — API access also offered.
- **Relevance: 8/10** — best free/local option if you have the VRAM; direct replacement for the community Hunyuan 2.1 node.
- **Windows + RTX?** Yes. 3.0 fits on 12 GB+ VRAM at reduced settings, 24 GB (4090/5090) comfortably.
- **Link:** https://blog.comfy.org/p/hunyuan-3d-30-in-comfyui-state-of

### Character / animation AI

**Sorceress** — recent, actively updated
- **What:** AI animation for rigged 3D characters; minutes vs. an afternoon of keyframing.
- **Price:** Freemium (credit-based, paid tiers not clearly disclosed on marketing page).
- **Relevance: 7/10** — solid for filler locomotion / reaction anims on humanoids; still weak on stylized skeletons.
- **Windows + RTX?** Yes (cloud).
- **Link:** https://sorceress.games/

**Reallusion iClone 8 — AI Video Mocap** — updated 2026
- **What:** Extract motion from ordinary phone video; retarget to a rigged character.
- **Price:** iClone 8 perpetual ~$599; subscription tiers available.
- **Relevance: 6/10** — great output, but the license price and pipeline weight put it above most solo budgets unless mocap is central to the game.
- **Windows + RTX?** Yes.
- **Link:** https://www.reallusion.com/iclone/

### Concept art / 2D asset generation

**Scenario, Leonardo.Ai, Layer.ai** — no fresh major release this window, but all shipped incremental updates
- **What:** Style-trained 2D asset pipelines (Scenario), general concept (Leonardo), tileable/game-first (Layer).
- **Price:** Scenario $30+/mo · Leonardo free tier + $12+/mo · Layer $30+/mo.
- **Relevance: 7/10** for Scenario (style-lock is what solo devs actually need); 5/10 for the others as tie-breakers.
- **Windows + RTX?** All cloud.

**ComfyUI 2026 partner-node additions worth naming:** Nano Banana 2 Lite (Google), Ideogram JSON prompt support via a new Bounding Box Canvas node, GPT-5.5 / 5.5-pro nodes. These are prompt/composition upgrades to your existing 2D graph — not standalone tools.

### AI-assisted coding (beyond Copilot)

**Claude Code** — Sonnet 4.6 default, current
- **What:** Terminal-native agent, 1M-token context, parallel background agents.
- **Price:** Free / Pro / Team; API-metered ($3 in / $15 out per M tokens on Sonnet 4.6).
- **Relevance: 9/10** — currently the best fit for Unity C# repos of any real size; large context handles the whole `Assets/Scripts` tree.
- **Windows + RTX?** Yes (cloud).
- **Link:** https://claude.com/code

**Cursor** — parallel-agents rework in H1 2026, still current
- **What:** IDE-native; dedicated Agents view; cloud agent environments (isolated repo copy per agent).
- **Price:** Free · Pro $20/mo · Business $40/user/mo.
- **Relevance: 8/10** — the multi-agent view is genuinely useful for fanning out refactors.
- **Windows + RTX?** Yes.
- **Link:** https://cursor.com/

**Devin Desktop (formerly Windsurf)** — rebranded 2026-06-02
- **What:** Cognition retired the Windsurf name; same Cascade UX now shipped as Devin's desktop client.
- **Price:** Free tier · Pro tiers align with prior Windsurf pricing (~$15/mo).
- **Relevance: 6/10** for solo Unity — cheaper than Cursor, but the rebrand caused churn and Devin's cloud-agent model is aimed at server-side codebases.
- **Windows + RTX?** Yes.
- **Link:** https://devin.ai/desktop

### Procedural generation / AI level design

_No headline release inside the 30-day window. State of the field:_

- **Dungeon Architect** (Unity/Unreal, Fab Marketplace) — the pragmatic pick, actively maintained.
- **Promethean AI** — environment dressing; still subscription, still slow for solo iteration.
- **Ludo.ai** — adds market analysis on top of level-gen; more useful for pitch prep than gameplay.

Solo relevance ceiling here is ~6/10 — most tools still need human-curated art to look non-slop.

### Voice / audio generation

**Cartesia Sonic-3.6** — released 2026-08-18 🆕
- **What:** Streaming TTS that now tops both Artificial Analysis speech arenas; ~40 ms time-to-first-audio on Sonic-3, further tuned in 3.6.
- **Price:** Paid API from $4/mo; commercial license from $5/mo.
- **Relevance: 8/10** — dynamic NPC dialogue that responds at conversational latency is finally a solo-buildable feature.
- **Windows + RTX?** Cloud API; nothing to run locally.
- **Link:** https://cartesia.ai/sonic

**Resemble Chatterbox v1.0.0** — recent
- **What:** 350M-param open zero-shot voice cloning model.
- **Price:** Open source (Apache-style); Resemble also sells hosted.
- **Relevance: 7/10** — good if you want an offline voice pipeline you fully own; requires GPU inference.
- **Windows + RTX?** Yes — runs on ≥8 GB VRAM.
- **Link:** https://github.com/resemble-ai/chatterbox

**NVIDIA ACE (on-device)** — GDC 2026 debut, shipped mid-2026
- **What:** Full avatar stack (ASR, LLM, TTS, animation) that now runs on-device on RTX. First production-grade TTS in the stack ships with the mid-2026 update.
- **Price:** Free SDK; commercial licensing for redistribution.
- **Relevance: 6/10** — powerful, but the runtime footprint is heavy for a solo indie's target hardware.
- **Windows + RTX?** Yes — this is the point of it.
- **Link:** https://developer.nvidia.com/ace

## Non-AI but powerful

### Unity plugins / packages

**Behavior Tools For Unity** — Asset Store, published June 2026, active 🆕 to the radar
- **What:** Visual behavior-tree authoring built on Unity's own Behavior Graph. Ships pattern library for patrols, boss phases, etc.
- **Price:** Paid (Asset Store listing — pricing not surfaced in search; ~$30–50 typical for this category).
- **Relevance: 9/10** — see the flag at the top. Direct upgrade over Behavior Designer for new projects.
- **Windows + RTX?** Yes (Editor-side tool; runtime is Unity's).
- **Link:** https://assetstore.unity.com/packages/tools/behavior-ai/behavior-tools-for-unity-371882

**Grabbit — Editor Physics Transforms v1.3.2** — updated 2026-08-13 🆕
- **What:** In-Editor physics for placing objects (stacks, drops, snaps) without hitting Play.
- **Price:** Paid (Asset Store); Grabbit 2 (Physics Placement + Collider Generation) also in current bundles.
- **Relevance: 8/10** — a genuine time-saver for scene dressing; solo devs feel this immediately.
- **Windows + RTX?** Yes.
- **Link:** https://assetstore.unity.com/ (search "Grabbit")

**Highlight Plus 2** — in August bundles
- **What:** Outline / silhouette / hover-highlight system with URP + HDRP + Built-in support.
- **Price:** Paid; ~$30 tier.
- **Relevance: 7/10** — near-universal need in games with selection or interaction.
- **Windows + RTX?** Yes.

### Blender addons

**Super Duper Batch Exporter** — major refactor April 2026, still current
- **What:** Batch export FBX/GLB/OBJ to Unity/Unreal/Godot with auto-LOD (decimate) on FBX export.
- **Price:** Free (Blender Extensions).
- **Relevance: 9/10** — see the flag; this is the pipeline glue you want.
- **Windows + RTX?** Yes.
- **Link:** https://extensions.blender.org/add-ons/superduperbatchexporter/

**Export Helper Pro** — recent
- **What:** Adds an N-panel with per-collection export presets for Unity/Unreal/Godot; one-click bake and export.
- **Price:** Paid (Superhive / Blender Market tier, typically $15–25).
- **Relevance: 8/10** — nicer UX than Batch Exporter if you like N-panel workflows; buy one of the two, not both.
- **Windows + RTX?** Yes.

**Auto-Rig Pro** — in August bundle refresh
- **What:** Guided humanoid/quadruped rigging with a dedicated Unity/Unreal/Godot exporter that bakes and remaps bones.
- **Price:** Paid, ~$40 on Superhive.
- **Relevance: 8/10** — still the pragmatic choice for character work in Blender for Unity's Humanoid rig.
- **Windows + RTX?** Yes.

### Performance profiling / optimization

**Unity 6 Profiler — Highlights module** — current in Unity 6.x
- **What:** New module shows performance vs. your target frame time at a glance; complements Profile Analyzer / Memory Profiler / Project Auditor.
- **Price:** Free (built into Unity 6).
- **Relevance: 9/10** — if you're on Unity 6 and haven't opened this yet, do it before your next optimisation pass.
- **Windows + RTX?** Yes.
- **Link:** https://unity.com/blog/use-unity-6-profiling-tools-smart-efficient

**Project Auditor** — actively updated 2026
- **What:** Static analysis for Unity projects — flags known perf pitfalls, shader/material issues, project-settings gotchas.
- **Price:** Free package.
- **Relevance: 8/10** — surfaces problems a solo dev doesn't have a lead engineer to catch.

### Pipeline automation

**Steamworks SDK v1.65** — re-released 2026-07-27, patched 2026-07-31 🆕
- **What:** Rebuilt Win32 `steam_api` binaries; fix to `ISteamApps::GetBetaInfo` not setting the `punLastUpdated` out parameter.
- **Price:** Free.
- **Relevance: 8/10** — if you're shipping on Steam, take the update; the beta-info bug is subtle but real.
- **Windows + RTX?** Yes.
- **Link:** https://partner.steamgames.com/downloads/list

### Playtesting / analytics

**FirstLook 1.0** — GA February 2026, feature set stable in this window
- **What:** Playtesting + community CRM + creator campaigns on one platform.
- **Price:** **Free forever for up to 500 playtester seats** (all Standard features, no card) · Self-serve $199/mo · Publisher custom.
- **Relevance: 9/10** — the free tier is genuinely usable for solo scope. Worth adopting even if you only use it for build distribution + feedback capture.
- **Windows + RTX?** Yes (web).
- **Link:** https://firstlook.gg/pricing/

**Antidote / Playcocola** — mentioned in 2026 roundups
- Antidote captures footage + facecam + inputs with Steam/Xbox integration.
- Playcocola is web-based, no install, aimed at indies.
- **Relevance: 6/10** each — useful if FirstLook doesn't fit; not standout in this window.

## Actions worth taking this month

1. **Swap the ComfyUI 3D leg** to Tripo 3.1 or Hunyuan 3D 3.0 Partner Nodes. Retire the community Hunyuan 2.1 custom node.
2. **Replace the manual Blender→Unity export** with Super Duper Batch Exporter (free) or Export Helper Pro (paid, nicer UX).
3. **If your enemy AI is on Behavior Designer or a hand-rolled state machine**, evaluate Behavior Tools For Unity before your next combat iteration.
4. **Pull Steamworks SDK v1.65** — small update, real bugfix.
5. **Open Unity 6's Profiler Highlights module** — 5 minutes; catches missed frame-time budget.
